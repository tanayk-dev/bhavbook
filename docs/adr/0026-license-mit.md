# ADR-0026: MIT licence

**Date**: 2026-10-19
**Status**: accepted
**Deciders**: Project author (Tanay), with Claude Code

## Context

BhavBook is a community open-source project with no business to protect. The goal is adoption and broker-adapter contributions.

## Decision

The project is licensed under **MIT**.

## Alternatives Considered

### Alternative 1: AGPL
- **Pros**: Forces hosted forks to share
- **Cons**: Discourages contributors and integrations
- **Why not**: No SaaS threat worth the friction

### Alternative 2: Apache-2.0
- **Pros**: Patent grant
- **Cons**: Heavier
- **Why not**: MIT is enough for this project

## Consequences

### Positive
- Maximum adoption

### Negative
- Others can build closed forks

### Risks
- None significant
